# Optional skills

This directory is empty in the public repository by design. The application ships with compact original fallback guidance, so AI features work without any third-party skill installed.

To enable a fuller local method library, install a skill by placing its folder here:

```text
skills/
├── chinese-novelist-skill/
│   └── SKILL.md
├── story-long-write/
│   └── SKILL.md
└── ...
```
